# ☕ Java Learning Journey

Welcome to my Java learning repository, built from the **IITMBS Data Science and Programming course** primarily. 

This space is where theory meets practice — through notes, code, and mini-projects that grow in complexity week by week.

## 📦 What’s Inside

This repo contains:
- 📘 **Lecture Notes** — distilled concepts for quick review
- 💻 **Code Snippets** — examples from lectures and beyond
- 🧪 **Practice Programs** — hands-on exercises for each topic
- 🚀 **Mini Projects** — built to reinforce learning through implementation
- 🔗 **Resources** — curated links to books, videos, and references

## 🧭 Learning Levels & Weekly Breakdown

This repo is organized into **8 progressive levels**, each mapped to weekly topics and project complexity:

| Level | Focus Area                        | Weeks Covered | Sample Projects                      |
|-------|-----------------------------------|---------------|--------------------------------------|
| 🟢 1   | Fundamentals & Console Apps       | 1–2           | Calculator, Quiz App                 |
| 🔵 2   | Object-Oriented Design            | 3             | Library System, Shape Hierarchy      |
| 🟠 3   | Abstraction & Interfaces          | 4             | Strategy Game Engine, Plugin System  |
| 🟣 4   | Generics & Collections            | 5–6           | Contact Manager, Inventory Tracker   |
| 🟤 5   | Robustness & File I/O             | 7, 9          | Logger, File-Based To-Do List        |
| ⚫ 6   | Functional & Stream-Based         | 8             | Stream Filter, Report Generator      |
| 🔴 7   | Concurrency & Threading           | 10–11         | Chat Server, Threaded Scheduler      |
| 🟠 8   | GUI & Event-Driven Programming    | 12            | GUI Calculator, Form App             |

Each folder includes:
- `Notes.md` — key concepts and examples  
- `src/` — Java files for hands-on practice  
- `README.md` — weekly summary and project goals

## 🛠️ How to Use

Clone and explore the repo by following the steps:

```bash
git clone https://github.com/CodeNaveen-in/Java.git
cd Java
code .
```

Use any IDE (VS Code, IntelliJ) or terminal to run the Java files.

This repo is my personal journey — but also a resource for anyone learning Java through structured, project-based exploration.
