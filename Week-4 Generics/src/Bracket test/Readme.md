 i.e. whether the pairs and the order of  "{ ",  " } ”, " ( ", " ) ”, " [ ", " ] ” are correct in the given input.

After all the expressions are input, for each input, the program should print whether the given expression is balanced or not (the order of the output should match the order of the input).
