## Key Concepts Illustrated:
- Inheritance: Employee extends Person, and ContactEmployee extends Employee.
- Constructor chaining: Each subclass calls its superclass constructor using super(...).
- Polymorphism: The print() method is overridden in Employee, and used polymorphically in the loop.
- Encapsulation: Fields are private and accessed only within their class.
