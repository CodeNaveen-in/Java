## Intro to Java
- Java is a high level, OOP language. 
- It was developed by Sun microsystems in 1995.

### Features of Java
- Object Oriented Programming.
- Platform Independence.
- Robust and Secure.
- Multithreading and Concurrency.
- Rich API and libraries.
- Frameworks for Enterprise and Web Development.
- Open Source Libraries.
- Maintainability and Scalability.

### First Program

```java
// This is a single comment

/*
multi line comment 
*/

public class HelloWorld { //name of the class
    public static void main(String[] args) { //main method of the program
        System.out.println("Hello World!"); //output statement
    }
}
```
### How does program run?
1. File is saved with the main class name.
2. Java Compiler (javac) compiles it to bytecode.
3. JVM reads the .class file and interprets the bytecode.
4. JVM converts the bytecode to the machine readable code.
