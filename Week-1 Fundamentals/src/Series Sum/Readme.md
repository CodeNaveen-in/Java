# Write a program to find the sum of the following series up to n terms.
12 + ( 12 + 22 ) + ( 12 + 22 + 32 ) + ......... + ( 12 + 22 + .... + n2 )

## What this program does:
- It calculates the sum of squares in a nested series like this:
$ 1^2+(1^2+2^2)+(1^2+2^2+3^2)+\dots +(1^2+2^2+\dots +n^2) $ - For example, if n = 3, it computes:
$ 1^2+(1^2+2^2)+(1^2+2^2+3^2)=1+(1+4)+(1+4+9)=1+5+14=20 $
