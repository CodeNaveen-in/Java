## Key Concepts Demonstrated:
- Custom Iterator Pattern: Implements a user-defined Iterator interface.
- Inner Class: SeqIterator accesses outer class members like iArr and size.
- Encapsulation: Sequence hides its internal structure and exposes iteration via get_Iterator().
- Abstraction: The user interacts with the sequence through the iterator without knowing its internal structure.
